VTKHDF.jl

VTKHDF.jl provides helpers for writing VTKHDF files that can be opened in ParaView.

Installation

VTKHDF.jl is not registered yet, so install it directly from GitHub:

using PkgPkg.add(url = "https://github.com/AhmedSalih3d/VTKHDF.jl")

Quick start

using StaticArraysusing VTKHDFpoints = rand(SVector{3,Float64}, 500)SaveVTKHDF("points.vtkhdf", points)

Point-data arrays can be supplied together with their names:

temperature = rand(500)SaveVTKHDF("points.vtkhdf", points, ["temperature"], temperature)

API

VTKHDF.SaveVTKHDF — Function
SaveVTKHDF(filepath, points, [variable_names], point_data...)

Write points and optional named point-data arrays to a VTKHDF PolyData file. Each entry in variable_names must have a matching array in point_data.
