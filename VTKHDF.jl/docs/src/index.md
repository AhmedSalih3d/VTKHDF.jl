# VTKHDF Documentation

Welcome to the VTKHDF documentation.

This documentation site is generated with Documenter.jl.

## Getting Started

To build the docs locally:

```julia
cd("$(dirname(@__FILE__))")
julia --project=. make.jl
```

## Package

VTKHDF provides helpers for working with VTK and HDF data in Julia.

For usage examples, add content under `docs/src/` and rebuild.
